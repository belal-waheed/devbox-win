Kahn's Topological DAG Engine

12 provisioner modules mathematically sorted by dependency graph. Prevents race conditions, detects cyclic loops, and guarantees runtimes precede editor configurations.

Unprivileged Native Symlinks

Elevate-once bootstrap check enables Windows Developer Mode in the registry. Your dotfiles stay live via NTFS symbolic links without requiring constant admin privileges.

Curated Tiling Desktop (Rice)

Signature out-of-the-box GlazeWM setup featuring DWM hardware cloaking to eliminate window flicker, Catppuccin lavender border, Nord Zebar widget bar, and Zed editor.

Circuit-Breaker Process Runner

180-second timeout guard on WinGet installer processes. If a package triggers a background modal or locks up, the runner kills it cleanly without hanging the bootstrap run.

Collision-Proof State & Rollback

Scoped parent prefixing and collision hashes ensure files like settings.json never overwrite each other in backups. Full reversal available via -Uninstall.

Disaster Recovery & Health Doctor

17 machine health diagnostics (`-Doctor`), SHA256 verified backup archives (`-Backup`/`-Restore`), 2-way cross-machine Git sync (`-Sync`), and an Edge Companion App.

Online Workstation Configurator

Design your tailor-made Windows 11 machine configuration online. As you toggle packages and options, your config.yaml and customized one-liner update dynamically.

Quickstart Guide

              
Get up and running on any Windows 11 machine in under 90 seconds.

              
Prerequisites

              
    
                
  • Windows 11 64-bit (Build 22000 or newer)
    • 
                
  • Internet connection for WinGet and GitHub package downloads
    • 
                
  • Standard user account (administrative elevation prompt appears once to enable Developer Mode for unprivileged symlinks)
    • 
              

              
One-Liner Execution

              
Open Windows Terminal (PowerShell) and run:

              
irm https://raw.githubusercontent.com/belal-waheed/devbox-win/master/bootstrap.ps1 | iex

            


            
            

              
CLI Command Reference

              
All operations are driven via core/engine.ps1 or standalone switches:

              
Diagnostics & Monitoring

              
# Run 17 machine health checks
pwsh -NoProfile -File core/doctor.ps1

# Launch Edge companion web dashboard
pwsh -NoProfile -File core/dashboard.ps1 -Open

              
Disaster Recovery

              
# Create compressed SHA256 snapshot
pwsh -NoProfile -File core/backup.ps1

# Restore workstation state from archive
pwsh -NoProfile -File core/backup.ps1 -Restore "backup.zip"

              
Multi-Machine Synchronization

              
# Check status against upstream git remote
pwsh -NoProfile -File core/sync.ps1 -Status

# Push or pull local dotfile changes
pwsh -NoProfile -File core/sync.ps1 -Push
pwsh -NoProfile -File core/sync.ps1 -Pull

            


            
            

              
Kahn's Topological DAG & Symlinks

              
devbox-win avoids race conditions and cyclic dependencies by calculating an in-degree topological order using Kahn's algorithm before any execution starts.

              
The 12 Ordered Modules

              
packages → fonts → envvars → git → shell → editor → runtimes → databases → keybindings → glazewm → zebar → dotfiles

              
Unprivileged Symlink Engine

              
NTFS symbolic links are created using the Windows 10/11 unprivileged symlink flag (SYMBOLIC_LINK_FLAG_ALLOW_UNPRIVILEGED_CREATE). If Developer Mode is disabled, bootstrap.ps1 prompts once for elevation, sets the registry key, and drops down to user privileges for all subsequent operations.
