Technical Engine Deep-Dive

Why Imperative Shell Scripts Fail Windows Machines

Windows environments present unique challenges: UAC traps, locked files, path bloat, and fragile subprocess lifecycles. Here is how devbox-win's DAG supervisor solves them.

Kahn's Topological DAG

Modules declare explicit dependencies. Kahn's algorithm validates the graph, detects circular cycles at compile time, and computes optimal parallel execution stages.

Lifecycle Supervisor

Implemented in core/lifecycle.ps1. Catches child process faults, enforces timeout containment, and never terminates the host terminal on failure.

Native Unprivileged Symlinks

Leverages Windows 11 Developer Mode FSCTL_SET_REPARSE_POINT. Dotfiles live once in git and symlink across user profiles without administrator prompts.

Architectural Dimension Traditional Shell Scripts (Bash / Batch / PS) devbox-win DAG Engine
Execution Model Linear top-down script — fails to parallelize or manage stage ordering. 12-Stage Kahn Topological DAG with deterministic phase resolution.
Dependency Graph Implicit & unchecked — circular imports cause silent deadlocks or crash. Compile-Time Cycle Detection with human-readable cycle traces.
Dotfile Linking Copies files or requires UAC — leaves duplicate files out of sync. Unprivileged NTFS Reparse Points via Windows 11 Developer Mode.
Process Lifecycle Fragile host shell — errors terminate your terminal or freeze sessions. Non-Terminating Supervisor with explicit exit code isolation.
Custom Drive Roots Hardcoded to C:\ — fills primary OS drive without fallback. Explicit --InstallLocation support with automated safe fallback.
State Tracking & Rollback Zero tracking — machines remain corrupted if aborted halfway. Deterministic state.json + SHA256 snapshot backup/restore.
Machine Health Auditing Manual troubleshooting — no automated health verification. 17-Point Automated Health Doctor (devbox-win -Doctor).

CLI & Companion Utility Reference

devbox-win is not just an installer; it is your workstation's daily maintenance utility. Run single commands to audit, backup, sync, or export PC state.

Click any command to copy to your clipboard
devbox-win Launches the native hardware-accelerated WPF companion GUI with package browser and path selector.
devbox-win -Preset <name> Provisions machine headlessly using a curated preset (belal-catppuccin, fullstack, frontend, backend, minimal).
devbox-win -Doctor Performs a 17-point machine health audit across runtimes, symlink reparse points, PATH, and Winget health.
devbox-win -Backup Creates a timestamped SHA256 disaster recovery zip archive of config, dotfiles, state, and SSH keys.
devbox-win -Restore -File <path> Extracts and restores workstation state from a previous snapshot archive with manifest verification.
devbox-win -Sync -Push / -Pull Bi-directional git synchronization for dotfiles and configurations across multiple developer machines.
devbox-win -Export Scans the active workstation and reverse-engineers installed Winget apps and system settings into config.yaml.
devbox-win -InstallLocation "D:\Tools" Overrides the global installation target directory for all compatible Winget packages.
devbox-win -DryRun Simulates full DAG compilation and execution plan without modifying any filesystem or registry state.
